# Домашнее задание к работе 3

## Условие задачи
**Задание 27.** Написать и отладить программу расчета плотности населения по заданной площади территории и числу жителей.

Плотность населения рассчитывается по формуле:

**Плотность = Число жителей / Площадь территории**

---

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**
2. Объявить переменные:
   - `area` — площадь территории (км²)
   - `population` — число жителей (чел.)
   - `density` — плотность населения (чел./км²)
3. Ввести исходные данные:
   - `area` — площадь территории
   - `population` — число жителей
4. Проверить условие: если `area == 0`, вывести сообщение об ошибке и завершить программу
5. Вычислить плотность населения:
   - `density = population / area`
6. Вывести результаты расчетов:
   - Площадь территории
   - Число жителей
   - Плотность населения
7. **Конец**

## 2. Реализация программы
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>

int main() {
    setlocale(LC_CTYPE, "RUS");

    float area;          
    float population;    
    float density;       

    printf("=== РАСЧЕТ ПЛОТНОСТИ НАСЕЛЕНИЯ ===\n\n");
    printf("Введите площадь территории (кв/км): ");
    scanf("%f", &area);
    printf("Введите число жителей (чел.): ");
    scanf("%f", &population);
    if (area == 0) {
        printf("\nОшибка! Площадь территории не может быть равна нулю.\n");
        return 1;
    }
    density = population / area;
    printf("\n===============================================\n");
    printf("         РЕЗУЛЬТАТЫ РАСЧЕТА\n");
    printf("===============================================\n\n");
    printf("Площадь территории:    %10.2f кв/км\n", area);
    printf("Число жителей:         %10.2f чел.\n", population);
    printf("-----------------------------------------------\n");
    printf("ПЛОТНОСТЬ НАСЕЛЕНИЯ:   %10.2f чел./кв/км\n", density);
    printf("===============================================\n\n");
    return 0;
}
